# CreditMesh 🌐

> **Empowering Gig Workers & Micro-Entrepreneurs with Explainable Financial Reliability Profiles**

CreditMesh is an alternate credit scoring and financial health platform designed for informal and gig economy workers (delivery partners, street vendors, freelancers, micro-business owners) who lack formal CIBIL/bureau credit histories.

---

## 🚀 Key Features

1. **Seamless Onboarding & Role Selection**
   - Instant mobile OTP verification.
   - Persona customization: Gig Worker, Street Vendor / Kirana, Freelancer, Micro-Shop.
   - Personalized user profile and identity setup.

2. **Explainable Financial Reliability Score**
   - Dynamic 0–100 reliability scoring based on income consistency, payment discipline, and cash flow stability.
   - Transparent profile breakdown showing why a user qualifies for financial options.

3. **Multilingual Regional Support**
   - Fully localized in **5 Indian languages**:
     - English
     - Hindi (हिंदी)
     - Kannada (ಕನ್ನಡ)
     - Tamil (தமிழ்)
     - Telugu (తెలుగు)
   - Dynamic instant translation across navigation, profile details, preferences, security, and verification.

4. **Cash Flow & Transaction Management**
   - Income & expense tracking with live cashflow metrics.
   - UPI transaction logging with automatic reference IDs.

5. **Invoicing & Micro-Business Bookkeeping**
   - Create, track, and manage client/customer invoices.
   - Status updates (*Paid*, *Pending*, *Overdue*) with SQLite database persistence.

6. **Privacy & Data Consent Controls**
   - Granular toggles for sharing banking signals, gig earnings, and utility records.
   - User-controlled profile visibility and data export/deletion.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript (Fast, responsive, zero heavy build dependencies).
- **Backend**: Python (Flask REST API), SQLite3, Flask-CORS.
- **Architecture**: Modular client-server with graceful offline demo fallback support.

## ⚡ Quick Start

### 1. Prerequisites
- Python 3.10+ installed.

### 2. Run Backend Server
```bash
cd Backend
pip install -r requirements.txt
python app.py
```
*Backend runs locally at: `http://127.0.0.1:5000`*

### 3. Open Frontend
Open `Frontend/alandingpage.html` in your web browser (Google Chrome, Microsoft Edge, etc.).
